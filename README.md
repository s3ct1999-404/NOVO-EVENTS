# Novo Events

Premium event production and technical solutions website for Novo Events, Kampala, Uganda.

## Tech Stack

- **Next.js 15** (App Router)
- **React 19** + **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Shadcn UI** (Radix primitives)
- **React Hook Form** + **Zod**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Pages

| Route | Description |
|-------|-------------|
| `/` | Cinematic homepage |
| `/about` | Company story and values |
| `/services` | Full service catalog |
| `/equipment` | Equipment hire inventory |
| `/portfolio` | Featured projects |
| `/gallery` | Photo gallery with lightbox |
| `/testimonials` | Client testimonials |
| `/team` | Team members |
| `/faq` | Frequently asked questions |
| `/booking` | Event booking form |
| `/quote` | Quotation request form |
| `/contact` | Contact form and info |
